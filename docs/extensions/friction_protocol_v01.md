# Wet flat-bed Manning forward proposal, v01

This protocol records the proposal at the completed 25-update pilot stage, before the full fit reported in [full findings v01](friction_full_findings_v01.md). Its immutable protocol is `runs/p08_friction_e1_seed11_pilot_v01/protocol.json`, with content digest `b49eac414c46959d4d0ff0fb376de19c1c6cca3b2dc939ec2a1420357dbb2360`. This digest excludes the protocol's own digest field; the pilot findings also record the file-byte SHA256.

Use wet E1 on x=[−5,5] m, dam at zero, hL=1 m, hR=0.1 m, u=0, g=9.81 m/s², T=0.5 s and initial volume 5.5 m² per unit width. Both ends retain their E1 reservoir targets. Bed elevation and rainfall are zero. The fixed illustrative n=0.03 s/m^(1/3) was chosen before this experiment. It is neither fitted nor attributed to a field site. The unchanged core E1 file supplies geometry, IC, BC and scales; the extension configuration supplies the friction source independently of that file's source-free assumption.

Momentum receives Sq=−g n²q|q|/h^(7/3); there is no mass source. Friction slope is n²q|q|/h^(10/3). The scaled momentum residual adds C q*|q*|/h*^(7/3), with C=g n²Lc/H^(4/3). The original model, scaling, IC/BC targets and sampler are reused without changing core source. The PINN retains the disclosed softplus depth floor 10⁻⁶ in scaled units. The numerical reference has no depth floor or source threshold.

The frozen design uses seed 11, CPU float32, four threads, four 64-unit tanh layers, 10,000 fixed PDE points, 1,000 IC points and 500 points per boundary. Adam has learning rate 0.001 and proposed budget 10,000 updates. Weights are fixed at PDE/IC/BC=1/10/10. The unchanged baseline validation contract supplies 365 PDE points, 72 IC points and ten boundary points, all with physics/IC/BC supervision only. The earliest strict minimum of that validation objective selects the checkpoint, including the initial state and every update. Final-reference errors cannot select settings or checkpoints. No interior solution labels, LBFGS, adaptation or viscosity are included.

The pilot stores fixed training, validation and final/auxiliary memberships, initialization bytes and parameter identity, source/configuration hashes, primary-source evidence hashes and the entire reference-packet inventory. Disjointness checks use float64 coordinates and the actual float32 query cast-then-scale order. Auxiliary boundary trapezoid nodes that collide with training/validation memberships are removed before fitting; t=0, T and all report times remain. The resulting base/refined axes have 999 and 1999 nodes. These axes are stored as exact arrays rather than regenerated during evaluation. The 12,000 training rows contain 11,998 unique coordinates after float32 conversion; their original multiplicities remain in the objective. This internal repetition produces no cross-partition overlap.

The separately verified reference uses first-order finite-volume HLLE with Einfeldt speeds, a homogeneous Euler step followed by exact fixed-h Manning decay, and fixed reservoir ghost cells. The positive-n matrix is 800/1600/3200 cells at CFL 0.45 and a separate 3200-cell run at CFL 0.225. The latter is the selected numerical reference. Native numerical boundary fluxes, actual source impulses, mass and momentum budgets, timestep histories, spatial/time differences and front uncertainty remain saved. The [reference method note](friction_reference_checks.md) gives the pinned primary sources and exact-version license provenance. The fine-grid result has measured numerical uncertainty; no analytical friction solution is claimed.

Final comparison uses 400 equal common cells and 50 positive times 0.01–0.50 s. Reference cell averages are conservatively projected to the common cells. The PINN h and q fields are integrated over each common cell with three-point Gauss–Legendre quadrature; five-point quadrature measures sensitivity. Neither field is silently interpreted as a cell-centre point value.

Velocity is the ratio of common-cell averages, qbar/hbar, for both methods. It is reported as **cell-ratio velocity**, with the fixed reference mask hbar>0.001 m. It is not a point velocity or an average of point velocities. Whole-domain, numerical-front-band and outside-band errors remain separate. The front rule and uncertainty come entirely from the numerical matrix; the frozen band half-width is 0.1 m for all 50 times. No analytical shock claim is made for positive friction.

Mass diagnostics use midpoint volume integration on 800/1600 cells at t=0 and all report times, and both endpoint discharges with base/refined trapezoid axes. Report M(t)−5.5+integral(qR−qL), predicted initial-volume bias, the balance after subtracting that bias, individual boundary h/q mismatches and absolute flux mismatch integrals. Preserve both spatial/time quadrature sensitivities and the raw arrays. Native reference momentum budgets use actual drag impulses; the mass diagnostic alone cannot verify drag.

The pilot queries and saves the full workload but withholds neural error and mass-quality reports. Diagnostic output cost uses reference-only and shape-only fixtures. A full run requires a release receipt with `state=released` and the exact content digest above, plus the frozen protocol. Final evaluation refuses pilot runs and verifies source, reference, memberships, initialization, history, selected checkpoint and every optimizer parameter state before using a released completed 10,000-update run.

This proposal covers one wet flat-bed synthetic case and one seed. At the pilot stage, full neural accuracy and sustained thermal behavior were untested. Inverse identifiability, dry states, nonflat well-balancing and field validation are outside this proposal. The accepted core, hybrid and planar packets retain their original findings and bytes.
