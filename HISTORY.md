# Development history

This repository contains the research portion of the original project history. Unrelated production files and working notes are excluded. The initial mixed foundation change is separated into setup, scientific implementation and tests. Commits that became empty after filtering are omitted.

The retained historical commits keep their recorded author and committer identities, dates and substantive messages. The publication packaging commit records the actual date this submission copy was prepared.

The [history map](docs/history-map.json) connects the original project commits to the retained publication commits. The original repository remains intact. Scientific inputs, source files, checkpoints and saved numerical results keep their recorded contents. Publication documentation repairs unavailable or machine-specific links, identifies historical records separately from distributed files, and updates obsolete workflow wording without changing reported scientific values. Project roles are listed in [CONTRIBUTIONS.md](CONTRIBUTIONS.md).
